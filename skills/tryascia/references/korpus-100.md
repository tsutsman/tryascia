# Курований корпус ТРЯСЦІ: 100 форм

Це перший seed-корпус для калібрування стилю. Він поєднує фольклорні формули, літературну розмовну мову, словниковий шар і сучасні інженерні адаптації. Записи не призначені для звертання до користувача.

**Рівень:** 1 — м’яко, 10 — критично.  
**Стан:** A — базова форма, B — природний словотвір, C — інженерна адаптація.  
**Джерельні коди:** С, Ф, Н, Г, К, Л пояснені у dzherela.md. Позначка →А означає власну інженерну адаптацію.
