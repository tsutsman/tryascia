# Безпека

ТРЯСЦЯ містить інсталятори, які записують файли до каталогів Codex і Claude Code. Перед запуском інсталятора:

- використовуй релізний тег або конкретний commit SHA;
- переглянь скрипт і перевір змінні `TARGET_CODEX_DIR` та `TARGET_CLAUDE_DIR`;
- не передавай у команди ключі, паролі чи інші секрети;
- для тестування використовуй окремий каталог.

## Повідомлення про проблему

Не публікуй у відкритих issues деталі, які містять секрети або дають змогу змінювати чужі файли. Для приватного повідомлення використай GitHub Security Advisories репозиторію або приватний канал зв’язку з підтримувачем.

У повідомленні вкажи:

1. уражений файл і версію/commit;
2. передумови відтворення;
3. фактичний вплив;
4. безпечний спосіб перевірки без секретів.

Цей файл описує процес повідомлення, а не гарантує відсутність уразливостей.
