# Участь у проєкті

ТРЯСЦЯ — експериментальний український інженерний стиль. Пропозиції мають покращувати точність відповіді, а не просто збільшувати кількість лайки.

## Новий запис корпусу

Для кожної форми додай:

- інженерне значення;
- рівень 1–10;
- джерельний шар і стан A/B/C;
- приклад технічного застосування;
- сторінку або конкретний запис, якщо він перевірений.

Якщо сторінку ще не підтверджено, запис має залишатися `candidate` і не може подаватися як дослівна цитата.

Не додавай довгі уривки з видань. Зберігай коротку форму, посилання та власне інженерне тлумачення.

## Правила стилю

- лайка описує баг, код, процес або ситуацію, а не користувача;
- не спрямовуй її на реальних людей, родини чи вразливі групи;
- security-попередження та незворотні операції залишай буквальними;
- публічні тексти, документація, коміти, PR і код мають бути чистими.

## Перевірка перед PR

```bash
npm test
bash -n install.sh install-codex.sh install-hermes.sh install-openclaw.sh tests/installer-smoke.sh tests/release-ref-smoke.sh
bash tests/installer-smoke.sh
bash tests/release-ref-smoke.sh
```

У PR коротко опиши, що змінилося, які джерела використано та які перевірки пройдено.
