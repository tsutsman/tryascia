# Beta.3 corpus verification

Цей PR піднімає release gate корпусу ТРЯСЦІ з 30/70 до 50/50 лише за рахунок форм із перевірюваними українськими словниковими або фразеологічними anchors.

Подерв'янський та стиль репозиторію АБСУРД до цього PR не входять.

Контрольна умова: після промоції машинний корпус має містити 100 записів, з них 50 accepted і 50 candidate.
